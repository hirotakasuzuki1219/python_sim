# 「コンピュータシミュレーション入門（仮）」 or 「物理現象をプログラミングで解いてみよう（仮）」
この授業では、計算用プログラムを自身の手で作成しながら、コンピュータシミュレーションを体感してもらいます。授業の中でシミュレーションの注意点や面白みに触れながら、ものづくり系エンジニアになるにあたって重要なスキルとなるシミュレーション技術の基礎を学んでもらえたらと思っています。

## 背景
- 高校物理では、数式で解くことができる（厳密解が求められる）問題が扱われてきた。
- 実際の現象はかなり複雑で、簡単に数式で扱うことが難しい。
  - 例：自動車の設計
    - タイヤと路面の接触、サスペンション、たくさんの部品との結合、…
- 複雑な物理現象を扱う際には、コンピュータシミュレーションが用いられる。
  - 製造業
    - 目標性能を満たしているか。
    - 製品はどのような挙動を示すか観察
  - ゲームエンジン
    - ゲーム内の物体が物理法則に従い動く
- ものづくり系エンジニアになるにあたって、シミュレーション技術を理解することは重要
- シミュレーションを学ぶ入り口となるような教材を提供したい。
  - 機械のシミュレーションやゲームエンジンなどがどのように動いているのかを想像しやすくなってほしい
  - シミュレーションの観察を通して物理の理解を深めつつ、面白みを感じてほしい。

## 講座の内容
- バネの振動を題材に、計算用プログラムを自身の手で完成させ、シミュレーションを体感してもらう。
  - 運動方程式 ($ma = F$) を数値解法（オイラー法）を用いて解いています。
  - 質点の動き（アニメーション）と、時間ごとの変位グラフを同期して表示。
    - 他の値も可視化予定
  - GIF保存機能: 実行後にシミュレーション結果を保存。
![シミュレーションGIF](results/simulation.gif)
- シミュレーションの注意点について理解してもらう
  - 失敗例：不適切な条件設定による誤差、発散
![シミュレーションの失敗例](results/simulation_error.gif)
  - 実験（バネでおもりをぶら下げて振動させる）との比較
    - 実際のバネはフックの法則（F=kx）が成り立っているか？
    - 実験でシミュレーション通りまっすぐ落とせるか？
    - バネはずっと振動しているか？（減衰、空気抵抗、…）
- 簡単なものの設計を体験し、シミュレーションの活用例を体感してほしい。
  - バンジージャンプのゴム
  - タイヤのサスペンション
- シミュレーション結果の観察を通して、力学の理解を深めてほしい。
  - 数式だけではイメージのしにくかった振動をアニメーションとグラフで再確認

## 計算用プログラム

Python パッケージ管理ツールとして `uv` を使っています。

```bash
# リポジトリのクローン
git clone https://github.com/hirotakasuzuki1219/python_sim.git
cd python_sim

# 仮想環境の作成とライブラリのインストール
uv venv
uv pip install -r requirements.txt
```
