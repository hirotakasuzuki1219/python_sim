# コンピュータシミュレーション入門（仮）、物理現象をプログラミングで解いてみよう（仮）
この授業では、計算用プログラムを自身の手で作成しながら、コンピュータシミュレーションを体感してもらいます。授業の中でシミュレーションの注意点や面白みに触れながら、ものづくり系エンジニアになるにあたって重要なスキルとなるシミュレーション技術の基礎を学んでもらえたらと思っています。

## 背景
- 高校物理では、数式で扱うことのできる問題が扱われてきた。
- 実際の現象はかなり複雑で、簡単に数式で扱うことが難しい。
  - 例：自動車の設計
    - タイヤと路面の接触、サスペンション、たくさんの部品との結合、…
- 製造業などでは、コンピュータシミュレーションを用いて、製品の性能予測が行われる。
  - 目標性能を満たしているか。
  - 製品はどのような挙動を示すか
- ものづくり系エンジニアになるにあたって、シミュレーション技術を理解することは重要
- シミュレーションを学ぶ入り口となるような教材を提供したい。

## 🚀 特徴

* 運動方程式 ($ma = F$) を数値解法（オイラー法）を用いて解いています。
* 質点の動き（アニメーション）と、時間ごとの変位グラフを同期して表示。
* **GIF保存機能**: 実行後にシミュレーション結果を自動保存。

## 🛠 セットアップ

このプロジェクトでは Python パッケージ管理ツールとして `uv` を推奨しています。
