# バネマスシミュレーション（物理シミュレーション入門）

このプロジェクトは、プログラミングを通じて物理現象（バネの鉛直振動）をシミュレーションし、理想と現実の差や計算誤差について学ぶための教育用教材です。

## 🚀 特徴

* **物理に基づいた計算**: 運動方程式 ($ma = F$) を数値解法（オイラー法）を用いて解いています。
* **鉛直方向への拡張**: 重力加速度を考慮し、自然長から「つり合い位置」を中心とした振動を再現。
* **リアルタイム可視化**: 質点の動き（アニメーション）と、時間ごとの変位グラフを同期して表示。
* **実時間同期**: タイムステップ ($dt$) と描画FPSを連動させ、現実の時間軸に合わせた再生が可能。
* **GIF保存機能**: 実行後にシミュレーション結果を `simulation.gif` として自動保存。

## 🛠 セットアップ

このプロジェクトでは Python パッケージ管理ツールとして `uv` を推奨しています。

```bash
# リポジトリのクローン
git clone [https://github.com/hirotakasuzuki1219/python_sim.git](https://github.com/hirotakasuzuki1219/python_sim.git)
cd python_sim

# 仮想環境の作成とライブラリのインストール
uv venv
uv pip install -r requirements.txt
