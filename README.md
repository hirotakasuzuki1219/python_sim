# バネマスシミュレーション（物理シミュレーション入門）

このプロジェクトは、プログラミングを通じて物理現象（バネの鉛直振動）をシミュレーションし、理想と現実の差や計算誤差について学ぶための教育用教材です。

## 🚀 特徴

* 運動方程式 ($ma = F$) を数値解法（オイラー法）を用いて解いています。
* 質点の動き（アニメーション）と、時間ごとの変位グラフを同期して表示。
* **GIF保存機能**: 実行後にシミュレーション結果を自動保存。

## 🛠 セットアップ

このプロジェクトでは Python パッケージ管理ツールとして `uv` を推奨しています。

```bash
# リポジトリのクローン
git clone https://github.com/hirotakasuzuki1219/python_sim.git
cd python_sim

# 仮想環境の作成とライブラリのインストール
uv venv
uv pip install -r requirements.txt
